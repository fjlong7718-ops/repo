
# PCBasic Interactive Prototype

  This is a code bundle for PCBasic. The original project is available at https://www.figma.com/design/TalpoTsDiZuLf7QTrlaR0c/PCBasic.

## Prototype scope

- Marketing home page and responsive navigation
- Instant PCB/PCBA quote configuration and file-upload flow
- Cart and checkout journey
- Account dashboard, orders, manufacturing progress, messages, coupons, and profile settings
- Supporting company, capability, solution, help, blog, news, legal, and contact pages

All commerce, upload, payment, manufacturing, and logistics data is simulated for prototype demonstration.

## Running the code

Run `pnpm install` (or `npm install`) to install dependencies.

Run `pnpm dev` (or `npm run dev`) to start the development server.

Run `pnpm build` (or `npm run build`) to create a production build in `dist/`.
